# builtbyingrid.com

Personal portfolio site for Ingrid Spielman. Hosted on GitHub Pages.

## Structure

```
index.html          - Main single-page site (About, Projects, Writing, Research)
research.html       - Detailed research page with animations and posters
articles/           - Local PDF copies of Techstars blog posts
images/             - Profile photo and research assets (GIFs, PDFs)
CNAME               - Custom domain config for builtbyingrid.com
```

## Development

No build step or dependencies. Open `index.html` in a browser, or run a local server:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Deployment

Pushes to `master` auto-deploy via GitHub Pages. Changes typically go live within 1-2 minutes.
